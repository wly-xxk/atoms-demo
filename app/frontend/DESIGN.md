# DESIGN

## Direction & Layout
- 产品：Vibe Coding 生成器——一句话描述，AI 生成可运行网页应用，左侧对话、右侧预览/代码。
- 氛围：暖奶油纸面 + 近黑墨色 + 唯一珊瑚色强调（#EF5466），沉稳可信，不做霓虹科技风。
- 首屏核心：深色圆角 Hero 中央的大标题 + 浮起的提示词输入卡（定义性视觉）。
- 布局：最大宽度 1200px；工作台为 2 栏（左 380px 对话 / 右自适应预览），<900px 上下堆叠。
- Do：强调色仅用于激活态和小信号；卡片圆角 16px + 细边框。Don't：渐变紫蓝、发光边框、第二种亮色。

## Tokens
- 颜色：背景 #E8E9DD，卡片 #F4F6F1，墨色 #141414，边框 #CDCCC3，弱文字 #6A6760，强调 #EF5466。
- 字体：Roboto（界面）、Roboto Mono（代码），Hero 标题 56–72px/700/行高 1.02/字距 -0.03em；正文 15px/1.6；标签 12px 大写字距 0.12em。
- 间距 4/8/12/16/24/40/80；圆角：按钮全圆角，卡片 16px，输入卡 24px。
- 阴影：输入卡 shadow-xl；普通卡片仅边框。

## Shared Patterns & States
- 提示词卡：textarea + 示例胶囊 + 圆形提交按钮；生成中禁用并显示进度文字。
- 对话气泡：用户深色、AI 卡片色；版本列表可点击回滚，当前版本强调色点。
- 状态：未登录显示登录按钮；生成失败 toast + 可重试；空项目显示引导。
- 动效：0.2s 颜色过渡，尊重 reduced-motion；焦点环 2px 强调色。

## Media
- 工具型界面，主体为生成预览 iframe，无需额外图片；Logo 用简单几何 SVG 标记。
